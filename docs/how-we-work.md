# How we work

By default all our discussions and outputs are public.

We use [GitHub issues](https://github.com/DAREUK/tetres/issues) for all discussions, and pull requests for updating content.

## Meetings

We currently meet fortnightly on Mondays at 14:00.
We take collaborative notes live during meetings using [Framapad](https://framapad.org/), then archive them to [Meeting notes](meetings/).

TODO: we are also looking at regular co-working sessions in between our formal meetings.

## Communication

In addition to [GitHub issues](https://github.com/DAREUK/tetres/issues) we have a private mailing list for anything that shouldn't be recorded in public.

## Outputs

All outputs will be available under a permissive open-source license.
This repository will include agreed standards and related documentation.
Source code for other outputs will be kept in their own repository and linked from this site.
