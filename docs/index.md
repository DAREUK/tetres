# TETREs: Test Environment for Trusted Research Environments

[:octicons-mark-github-16: DAREUK/tetres](https://github.com/DAREUK/tetres)

The Test Environment of Trusted Research Environments (TETREs) is validating the technologies that enable federated analysis in TREs.

It's a UK-wide network of TRE operators who are running a testbed to:

- look at low level networking technologies for securely connecting TREs to each other
- deploy open-source tools and platforms to demonstrate secure federated data analysis
- publish standards or recommendations for the technical implementation of a federated TRE network

TETREs is intended to mimic a production TRE federation as closely as possible so that we can provide realistic feedback on whether the technologies we're testing would be widely accepted by TREs, except that we will only use public non-sensitive data for testing.

Initially we are looking at tools created by projects funded by [DARE UK](https://dareuk.org.uk) and [HDR UK](https://www.hdruk.ac.uk), but once established TETREs will consider other relevant open-source tools from anyone.

In the longer term TREs that are thinking of joining a federation will be able to come to TETREs to see a demonstration of how it works.
